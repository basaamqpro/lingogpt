2. Password reset methods

Self-service

Method A — Change your own password

A logged-in user enters the current password. Firebase re-authenticates the account and then replaces the password with the new one.

This changes the password in Firebase Authentication. It does not store the password in Firestore or localStorage.
Educational option

Method B — Firebase password-reset email

Firebase can send a password-reset link to a real email address attached to the Authentication account.

sendPasswordResetEmail( auth, "user@example.com" );
In this tutorial, users sign in with a username and the project creates an internal Firebase email-like identifier behind the scenes. That identifier is not a real inbox, so the user cannot receive a reset email there. This method becomes useful if a future version collects a real recovery email.
Owner / server method

Method C — Admin resets another user's password

A project administrator can change another Firebase user's password with the Firebase Admin SDK by using the account's Firebase UID.

import { getAuth } from "firebase-admin/auth"; await getAuth().updateUser( firebase_uid, { password: "NewPassword123" } );
This code must run on a trusted backend, server, Cloud Function, or another protected administrator environment. Never place Firebase Admin private credentials inside this HTML page.
Account-recovery design

Method D — Add a recovery method later

For a username-only system, you can later add a real recovery email, verified phone number, or another verified recovery process. Once identity is verified, a secure backend can reset the Firebase Authentication password.

Do not reset a password merely because somebody knows a username. A real application needs proof that the requester owns the account.
